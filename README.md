# Cape Town agencies on Nostoi — research record

The working page lives in the Custom AI Solutions site repo
(`TheStevenJohnstone/cas-ai-nucleus`, branch `claude/nostoi-agency-marketing`) and is served at
`/nostoi-agency-marketing` once merged to `main`. This repo keeps the research behind it:

- `data/agencies.ts` — the 28-agency dataset (owners, offices, principals, published contacts,
  feed vendor, size estimate with source and confidence), as loaded by the page.
- `data/playbook.ts` — the outreach playbook (pitch, red lines, decision map, sequence, objections,
  message templates), written from the Nostoi Complete Platform Description v3 and Master V7.9.
- `data/research-notes-2026-09-29.md` — raw notes and sources from the research pass.

Research date: 29 September 2026. Agent counts are Private Property branch counts or ranges;
the confidence field on each record says how firm the figure is.
